# VibeBrowse
its completely vibecoded, hence the name

## whats vibebrowse

vibebrowse is an entirely (except for the dmg background) ai generated, vibecoded, web browser/glorified html viewer

its has:
- html editing
- site viewing via iframe (theres a preset, dont worry your vibe coded head off)
- back and forward buttons
- a run button to reload the html currently in the editor and to load the html
- a start page (does the mbappe special)
- cool icon (not vibecoded)
- cool name (not vibecoded)
- a pretty dmg background (made by me and my schools canva pro)
- and its all vibe coded! chatgpt plus free trial came in handy. (no not claude)
